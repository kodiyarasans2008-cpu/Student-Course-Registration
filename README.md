# Student Course Registration System - Final Mini Project

## Features
- Student login
- Officer/Admin login
- Student dashboard
- Course registration and drop
- Seat capacity checking
- Student profile
- Admin student/course/registration views
- Linked List for registered courses
- Linear Search for course search
- Bubble Sort for course sorting
- Browser localStorage for demo persistence
- Responsive UI
