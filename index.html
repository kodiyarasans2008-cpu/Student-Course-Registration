About Project

Student Course Registration System using data structures.

🔗

Linked List

Each student's registered courses are represented as nodes connected to the next node. Add and drop operations demonstrate insertion and deletion.

🔍

Searching

Linear Search checks courses one by one and returns a matching Course ID or name.

🔃

Sorting

Bubble Sort arranges available courses by ID, name, credits or seats.
